# Final-Year Intern – Intelligent Multi-Agent System for Odoo 19

Academic documentation of a final-year internship project integrating an intelligent multi-agent assistant with Odoo 19. This public repository presents the academic report, defence slides and a privacy-redacted demonstration; it intentionally excludes the professional implementation.

## Project scope documented by the academic material

The report describes an assistant architecture composed of specialized agents, orchestration, provider integrations and an Odoo-facing user experience. The demonstration records the assistant interacting with ERP screens. These are historical project artefacts, not a claim that the private company system is available here as open source.

## Repository contents

- `docs/academic-report-fr.pdf` — French final-year academic report (80 pages; the administrative cover was omitted in the supplied reduced copy).
- `presentations/odoo-mas-defense-fr.pptx` — French defence presentation.
- [Privacy-redacted demonstration (GitHub Release)](https://github.com/adamelakkaoui/final-year-intern-intelligent-multi-agent-system-for-odoo-19/releases/tag/academic-demo) — the ERP/contact area is blurred while the assistant panel remains visible.

## Architecture and technologies

The reviewed academic documents discuss Odoo 19, a modular multi-agent backend, language-model/provider integrations and deployment concerns. Exact implementation details, credentials, internal documentation and company-owned source are not reproduced in this repository.

## Installation and use

There is no installable code in this public documentation repository. Reproducing the system would require the professional source, an Odoo 19 environment, approved provider configuration and non-public deployment details. No configuration template is supplied because the corresponding implementation is excluded.

## Testing and limitations

The report and slides were inspected as academic documents. The demonstration was re-encoded from the lower-resolution submitted recording with source metadata removed and all ERP/customer/contact regions blurred; sample frames were visually reviewed afterward. The application was not executed during portfolio preparation. The 4K recording, internal user/administration guides, professional Git history and all source code remain excluded because public-sharing rights were not established and some media contains company/customer information.
